تعليمات نشر نجوم العرب v2.6.4-r16 على GitHub Pages
=====================================================

1) افتح المستودع: mralehsas/najoom-al-arab
2) ارفع محتويات هذه الحزمة إلى جذر الفرع main.
3) تأكد أن اسم الصفحة الرئيسية هو index.html.
4) افتح Settings ثم Pages.
5) اختر Deploy from a branch.
6) اختر الفرع main والمجلد / (root)، ثم Save.
7) بعد اكتمال النشر افتح رابط GitHub Pages الظاهر في صفحة الإعدادات.

مهم:
- ارفع الملفات الموجودة داخل المجلد، وليس المجلد نفسه.
- لا تغيّر اسم index.html.
- ملف .nojekyll يجب أن يبقى في جذر المستودع.
- البرنامج مستقل، ولا يحتاج مجلد assets خارجي.
