# نجوم العرب — v2.6.4-r16

حزمة النشر الكاملة لبرنامج **نجوم العرب** بصيغة HTML مستقلة ومهيأة للعمل عبر GitHub Pages.

## محتويات الحزمة

- `index.html` — البرنامج الكامل والصفحة الرئيسية للموقع.
- `.nojekyll` — يمنع معالجة Jekyll غير المطلوبة.
- `AUDIT_REPORT.md` — تقرير الفحص التقني للإصدار.
- `audit-results.json` — نتائج الفحص بصيغة JSON.
- `SHA256SUMS.txt` — بصمة سلامة الملفات الأساسية.
- `GITHUB_PAGES_DEPLOY_AR.txt` — تعليمات النشر بالعربية.
- `VERSION.txt` — معلومات الإصدار.

## معلومات الإصدار

- الإصدار: `v2.6.4-r16`
- عدد سجلات النجوم: **204**
- نمط التشغيل: ملف HTML واحد مستقل.
- الأصول: الخطوط والصور والبيانات الأساسية مضمّنة داخل `index.html`.
- الاتصال بالإنترنت مطلوب فقط عند فتح المصادر العلمية الخارجية.

## النشر على GitHub Pages

ارفع جميع ملفات هذه الحزمة إلى جذر الفرع `main`، مع إبقاء اسم الصفحة الرئيسية `index.html`.
بعدها فعّل GitHub Pages من:

`Settings → Pages → Deploy from a branch → main → / (root)`
