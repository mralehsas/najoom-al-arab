najoom-al-arab
نسخة مدققة ومهيأة للنشر على GitHub Pages بوصفها صفحة HTML مستقلة.

## الملفات

- `index.html`: البرنامج الكامل.
- `.nojekyll`: يمنع معالجة Jekyll غير المطلوبة.
- `AUDIT_REPORT.md`: خلاصة التدقيق التقني.
- `audit-results.json`: نتائج التدقيق بصيغة قابلة للقراءة آليًا.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع **محتويات هذا المجلد** إلى الفرع `main`، بحيث يكون `index.html` في جذر المستودع.
3. افتح: `Settings → Pages`.
4. اختر: `Deploy from a branch`.
5. اختر الفرع `main` والمجلد `/ (root)` ثم `Save`.
6. انتظر اكتمال عملية النشر، وسيظهر رابط الموقع في صفحة Pages.

## ملاحظات تشغيلية

- البرنامج يعمل من ملف واحد، والخط العربي والبيانات مضمّنة داخله.
- فتح المصادر العلمية الخارجية يحتاج اتصالًا بالإنترنت.
- الروابط الخارجية تفتح في تبويب جديد مع `noopener` و`noreferrer`.
- يجب إبقاء اسم الصفحة الرئيسية `index.html` كما هو.
